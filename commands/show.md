# /show working/0X

## 용도

working/ 또는 output/ 안의 특정 산출물을 조회.

## 사용법

```
/show working/00_context
/show working/01a_persona
/show working/01b_promise
/show working/01c_paid_full
/show working/02_hook
/show working/03_free_full
/show output/paid_plan
/show output/free_plan
/show output/decisions
```
