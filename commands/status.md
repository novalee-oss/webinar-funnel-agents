# /status

현재 작업 상태를 요약해서 보여준다.

## 용도

현재 어느 단계인지, 어떤 단계가 승인됐는지, stale 산출물이 있는지 한눈에 확인.

## 사용법

```
/status
```

## 출력 형식

```
상품: {상품명}
현재 단계: Stage {N} — {단계명}
승인 완료: [stage-0, 1a, 1b, ...]
Stale: [01c_paid_full.json, 02_hook.json, ...]
마지막 이벤트: {타임스탬프} {이벤트}
```
